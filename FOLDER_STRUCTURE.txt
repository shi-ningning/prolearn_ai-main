GETTING STARTED:

1. Install Prerequisites:
   - Flutter SDK (3.x+)
   - Node.js (18+)
   - Firebase CLI
   - Git

2. Frontend Setup:
   cd frontend
   flutter pub get
   flutter run

3. Backend API Setup:
   cd backend
   npm install
   cp env.example .env
   # Edit .env with your credentials
   npm run dev
   # API available at http://localhost:3000

4. Backend Functions Setup:
   cd backend/src/functions
   npm install
   npm run build
   cd ../..
   npm run emulators
   # Emulator UI at http://localhost:4000

5. Deploy:
   - Frontend: flutter build web
   - API: npm run build (then deploy to your hosting)
   - Functions: npm run deploy:functions
   - Database Rules: npm run deploy:rules

API ENDPOINTS:

Base URL: http://localhost:3000/api

Authentication:
  POST   /api/auth/login              - User login
  POST   /api/auth/register           - User registration
  POST   /api/auth/refresh            - Refresh access token
  POST   /api/auth/logout             - User logout
  POST   /api/auth/verify-email       - Send email verification

Users:
  GET    /api/users/:id               - Get user profile
  PUT    /api/users/:id               - Update user profile
  GET    /api/users/:id/stats         - Get user statistics
  DELETE /api/users/:id               - Delete user account

Projects:
  GET    /api/projects                - List user projects
  POST   /api/projects                - Create new project
  GET    /api/projects/:id            - Get project details
  PUT    /api/projects/:id            - Update project
  DELETE /api/projects/:id            - Delete project

Tasks:
  GET    /api/tasks                   - List user tasks
  POST   /api/tasks                   - Create new task
  GET    /api/tasks/:id               - Get task details
  PUT    /api/tasks/:id               - Update task
  DELETE /api/tasks/:id               - Delete task
  PATCH  /api/tasks/:id/complete      - Mark task complete

Analytics:
  GET    /api/analytics/overview      - Dashboard statistics
  GET    /api/analytics/progress      - Progress tracking
  GET    /api/analytics/export        - Export user data

Admin (requires admin role):
  GET    /api/admin/users             - List all users
  GET    /api/admin/stats             - System statistics
  POST   /api/admin/announcements     - Create announcement
  DELETE /api/admin/users/:id         - Delete user (admin)
